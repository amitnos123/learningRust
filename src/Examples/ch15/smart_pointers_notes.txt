Box<T>
------
Boxes allow you to store data on the heap rather than the stack.
They are just pointers for general data


Rc<T>
------
Which is an abbreviation for reference counting.

This type keeps track of the number of references to a value
to determine whether or not the value is still in use.
We use when we want to use a value in multiple places, and without need to pass the ownership betweenthem

When we don't want ownership, we can use Weak.
Weak is a version of Rc that holds non-owning reference to the managed allocation.

Weak.upgrade() to turn Weak type to Rc type
Rc.downgrade() to turn Rc type to Weak type

RefCell<T>
----------
Type represents single ownership over the data it holds.
Borrowing rules are enforced at runtime.
We use when we want to store change a variable, which normally stored as inmmutable
